Frame — Free Bootstrap 5 One-Page Template by uiCookies
https://uicookies.com/downloads/frame-free-onepage-html5-template-using-bootstrap/

WHAT'S INSIDE
  index.html            The template (single page)
  css/vendor/           Bootstrap 5 (minified)
  css/style.css         Template styles (style.min.css is the minified copy)
  css/frame-bs5.css     Animations + Bootstrap 5 adjustments
  js/vendor/            Bootstrap 5 bundle (includes Popper)
  js/custom.js          Template behavior — vanilla JavaScript, no jQuery
  fonts/icomoon/        Icon font
  img/                  Demo images (via Unsplash)
  scss/                 SCSS sources for style.css

NOTES
  - Built on Bootstrap 5. No jQuery, no plugin dependencies.
  - Scroll animations use IntersectionObserver and respect
    prefers-reduced-motion.
  - The contact form is front-end only; point the <form action> at your
    backend or form service to make it live.
